# 用户试用方案（尚未执行）

目标：检验参与者是否能独立完成试点配置、验证、提交与反馈理解。工程演示和合成数据不作为用户效果证据。

建议招募3–5名非实现者，征得同意后匿名编号；不采集真实客户资料或业务密钥。每人先阅读任务说明，完成一个主任务；记录开始/结束时间、求助次数、失败步骤、服务错误与主动放弃。主持人只解释操作，不提示试点答案；必要帮助逐次记录。

任务：读取材料并咨询角色；拟定试点；观察政策更新；执行至少一项功能与风险测试；修订并提交；阅读反馈并定位一条原证据。可通过现有 Swagger API 文档操作，但必须明确记录这种界面对完成时间的影响。前端排除期间不宣称普通用户可用性已通过。

试用后询问：最困惑的步骤、是否理解评分待核验、是否能找到原文、反馈是否误扣分、下一次会如何改进。人工按固定 rubric 独立评审提交与事件记录，记录分歧及仲裁，不用模型输出作人工真值。

记录表字段：匿名参与者ID、场景/版本、是否完成、耗时、人工帮助、错误步骤、反馈争议、引用可访问性、复现会话ID。原始记录本地访问受限，公开报告只保留去标识汇总。

探索性对照须另行冻结方案与评价规则，随机分配练习条件，在无提示新任务中测迁移表现。小样本仅用于发现问题，不宣称因果学习效果。当前没有招募、没有真实受试者数据、没有执行对照实验。
