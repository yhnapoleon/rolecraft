# 受控场景标注规范 v2

用途：课程监督学习、ML/DL与Ensemble实验；不作为真人职业能力真值。场景矩阵以src/career_lab/datasets/scenario_matrix.py为机器可执行版本。

## 单位与证据

一项为一个明确结论及若干有版本的候选材料。SUPPORTED表示材料足以证明结论；CONTRADICTED表示材料足以否定；INSUFFICIENT表示两者都不能证明。材料未提供某字段不代表字段为0，申请不等于批准，未来批准不影响历史时点。复合条件采用三值逻辑：且包含已知假即假，或包含已知真即真，其余缺项保持未知。

标注所有可接受的最小充分证据集合。多个可行分支可有不同集合；有无关引用不等于充分。INSUFFICIENT写明缺少的关键事实，不能因为未给某个非必要字段就判断不足。中性e编号与位置随机化；不在输入加入gold、生成模式、标签来源或作者事实结构。

## 人工流程

先由两位真实成员独立完成工作包的前30项，再比较分歧、修订标准；其余100项根据试验成本继续。不要查看程序gold，不讨论后再回填原始答案。填写annotator_id、label、evidence_sets（JSON二维数组）、missing_requirement、notes、minutes。每人一个CSV，保留独立原始记录。

导入会校验item/input hash、引用存在性、重复项、标签、标注者与耗时；两人必须使用不同ID。同标签但证据集合不同仍进入分歧列表。报告raw agreement、Cohen kappa和累计分钟数；空表只输出pending，不生成虚构的一致率。分歧由第三人或共同讨论裁决，另存裁决记录。

## 真值来源与范围

G0来自版本化逻辑验证器，保存相关字段及最小证据证明；G1需要真实人工核验与裁决；G2为模型弱标签。程序gold不自动升级为G1。当前v2为中文受控合成G0，不混入ContractNLI或把公开英文指标用于中文结论。

同模板及其数值变化、正反例、删除事实、改写与重排始终同split。同能力族在train/dev/test出现，不代表模板共享；各分区采用不同依赖结构。24是作者定义的结构数量，仍需要人工审查语义近重复，不能宣称24个独立真实业务场景。

生成语言目前采用确定性自然语言模板。模型可辅助提出改写，但未通过等价性与人工检查的文本仅作G2。严格语法规则的高分只适用于这类结构化输入。
