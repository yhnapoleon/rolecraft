## 助手生成模式（局部实现，待公共接线）

`AssistantConfig.generator` 支持 `extractive`（默认）和 `llm`；默认值不进入序列化，旧配置字节与 hash 保持。原抽取路径、已发布场景内容、审批与有效配置规则沿用原实现。
