## 正式契约与存储接入

ScenarioModule提供注册工厂，通过原有ExtensionRegistry安装场景及以下固定槽位，
不删除路由、不挂第二套router、不直接访问数据库私有方法：

- actions：配置、索引刷新、资料读取与业务申请。
- approvals.resolve：复用实际确定性策略，公共Mutation原子保存请求/决定并应用资源。
- tests.create / tests.list：真实执行、不可变结果与恢复。
- materials.list：授权目录；目录可见不等于学员已获得内容。

ScenarioStateV2保存源、索引、激活记录和当前配置引用；PlannedTransition转换为公共Mutation，
业务seq/workspace/storage版本由W01提交层决定。BusinessRequest使用正式BusinessBasis，
提议配置不冒充已应用配置。TestResultV2带execution/config_ref、实际时间/执行者、chunk、源与索引版本。
min_score、三态freshness_guard、manual_domains使用公共AssistantConfig；不能通过未入库的调参偷偷覆盖配置版本。

审批必要性和保障前提写入规则与学员材料。引用可选；合法user_groups等材料引用可参与真实审批。
决定给出可理解的拒绝原因，获批不会自动应用配置。原“policy”域名作为policy_travel的兼容别名，
实际检索与覆盖按规范化知识域记录。

baseline.json按AssistantConfig、roles.json按RoleSpecV2解析后比较规范化字段；
原始文件hash仍验证，未知字段、角色身份和披露差异仍拒绝。带默认值的字段不要求跳过清单验证。

凭据禁区保持原设置。严格完整匹配的公开流程问法只检索对应FAQ段，仍遵守知识范围和用户自设禁区；
索取实际密码/密钥和复合索取请求继续拒绝。该识别覆盖已测问法，未知表达仍可能转人工。

```sh

env -u PYTHONPATH .venv/bin/python -m career_lab.scenarios.v2 probes scenarios/pm_pilot/v2
env -u PYTHONPATH .venv/bin/python -m career_lab.scenarios.v2 public-probes scenarios/pm_pilot/v2

  --database-url sqlite:///runs/local/w02-new-session.db --port 19832
```
