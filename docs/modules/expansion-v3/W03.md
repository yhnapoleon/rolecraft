# W03 工作区模块

当前交付是基于 W01 不可变 draft 的独占模块实现，尚未接入正式 W01 事务层和现有工作台。不能据此宣称产品联调、W03 全部 AC 或最终产品 QA 已通过。

输入：基准 `80cf1f6189cd25610d609f44283ff9668582d759`，契约 `draft-391f39156eba1a56b7fbb1228484e5e31143027bfe637bf45fb029ec369d222e`。`contracts/v2/` 和 `contracts/versioning.py` 来自已核验归档，只读使用，不属于本包产出。

## 已实现的模块行为

- 事项可创建、按 priority/order 排序、改进展、暂放/阻塞和可恢复移除。以 parent 创建子事项，以 relations 创建合并处理事项，保留原事项和精确版本引用；父项循环会拒绝。批量拆合并自动更新所有来源事项还需要正式请求契约。
- 多种作品使用不可变版本；用途可为未知自然语言，内容不因 kind 被丢弃。内容 hash 由服务端计算，作者和执行者来自可信 AuthContext；后续人修改保留原作者。采用为显式动作，形成新版本，不等于业务批准或验证通过。
- 测试行/调查模块的 ID 和修改 revision 由服务端分配。人记录的调查判断不能被外部 Agent 覆盖或清空。
- 分享固定作品版本与同事。编辑不会自动分享新版；撤销或移除阻止未来读取，已保存版本与分享历史不改写。角色读取不返回 legacy 中的私人草稿/历史；引用来源不对该角色开放时整份读取拒绝，等待 W04 的明确过滤投影，避免引文泄露。
- 导入先 preview，再以 preview_storage_revision 执行 apply。同包异内容冲突；同请求重试恢复原结果。只把确实存在的历史快照转成连续服务端版本，并通过 `original_id@vN` 映射来源版本，缺失版本不补造。原本地副本不删除，未决请求不执行；异会话测试标失联，不计为新会话测试。
- 局部 SQLite 仓储原子提交版本、请求结果、审计记录与注入的公共状态版本更新；注入故障时一并回滚。重放前仍重新核对凭据；当前会话终态阻止新写入，旧成功请求可重放。
- 独立前端 feature 提供事项/作品组件、确切版本分享、导入选择/预览和草稿同步控制器。所有本地读改写在浏览器原生 Web Lock 内读取最新记录并按对象合并；网络执行使用独立的会话锁，另一标签页可继续保存文字。旧版本整个 journal 不会覆盖新格式记录。
- 草稿第一次编辑时固定基准作品和版本，刷新只更新服务端副本。基准不一致时展示双方文字与版本，普通保存被拒绝；只有明确比较/合并才推进基准。经同一写入者的已确认保存，并能从编辑谱系证明是连续编辑的草稿，可以跟进自己的成功版本。
- 请求进入 pending 前，在同一写锁内核对意图提交的 token、基准和正文是否仍为同一份草稿。期间有新输入就明确拒绝旧快照发送。ACK 还会独立核对 pending 正文与实际命令的绑定；旧记录如果曾错误绑定 token，也只恢复请求结果，不删除或推进未发送草稿。
- 明确未执行的冲突/拒绝退出 pending，但原输入进入持久 rejected 记录。用户可继续其他工作，核对后新键重提；导入必须重新预览。未知结果保留原键；如果此前结果未知，后续鉴权/校验失败不能倒推首次未执行。重新打开后仍保留这些状态。

## 模块入口与接线

```python
from career_lab.storage.workspace_v2 import register_tables
from career_lab.workspace.service import create_service
from career_lab.api.workspace_v2 import create_router

# engine、authority、trusted_auth_dependency 必须由 W01/032 提供。
register_tables(engine)
workspace = create_service(engine, authority)
app.include_router(create_router(workspace, trusted_auth_dependency))
```

`WorkspaceAuthority` 位于 `workspace/ports.py`，要求五个函数：

| 函数 | 必须由公共层保证 |
|---|---|
| `validate(conn, auth)` | 当前身份仍有效，包含撤销/到期；每次读取、写入和重放均检查 |
| `state(conn, auth, lock=...)` | 从同一事务读取真实 WorldStateV2；写时锁会话 |
| `advance_workspace(conn, auth, before, after)` | 同事务 CAS 更新 workspace/storage revision；不改 business_seq、资源、状态或里程碑 |
| `can_reference(conn, auth, ref)` | 确切对象/版本存在，属于会话且当前身份获准读取；不能只看 ID 格式 |
| `roles(conn, auth)` | 当前场景允许的角色 ID |

这里的 `Snapshot/Mutation` 是 W03 内部 Python 端口，未发布为另一套公共 schema。所有对象使用 W01 draft 类型。W01 manifest 提到的公共 `ObjectWrite/Mutation` 实现未包含在输入归档，032需将该端口接入正式事务服务或提供映射后再联调。

表注册只新增 `w03_workspace_versions`、`w03_workspace_requests`、`w03_workspace_audit`，不修改旧表。正式公共存储已有同类能力时，应以适配映射消除重复，不能同时维护两套权威时钟。当前生产模块没有用于创建世界或绕过业务 reducer 的本地替身。

路由工厂包含 work-items、work-products、版本、adoption、shares 和 workspace-imports。所有写入接收既有 draft `Command` 信封；`operation` 与 URL 不一致会拒绝。名称见 `workspace/domain.py::OPERATIONS`。`ProductEdit` 同时用于显式采用和移除/恢复；采用不接受内容变化。TaskPatch 的 null 表示不变，`clear_parent=true` 才清空父项。W01正式冻结需确认这些调用映射。

前端从 `apps/web/src/features/workspace/index.ts` 导入。`WorkspaceClient` 只接收 session ID、草稿存储与注入的 transport；凭据由既有 transport 持有，不写入 feature 存档或导出。组件供032接入现有事项、作品和导入槽位；不替换工作台 v4，不自动迁移任何用户存档。生成的 TypeScript 类型直接来自已核验 schema，可用同目录 `generate_types.py <manifest>` 重新生成。

浏览器默认要求安全上下文中的 `navigator.locks`。缺少跨标签协调能力时保留页面输入并拒绝写入，不能降级为仅单页互斥锁。`keepDraft` 返回 Promise，调用方可等待本机持久化；网络操作会先等待本机保存。`MemoryCoordinator` 只在测试辅助代码中使用，禁止接到真实浏览器。

本地格式 `schema=2` 存在新 `journal2` key，包含每份草稿的基准、写入者、编辑 token/谱系、其他草稿副本、pending 和 rejected。读取旧 `schema=1` 时保留原 key；旧稿缺少基准就标为未知，不能据新读取的 head 补造。跨标签协调保证持久数据完整；其他标签页可通过刷新读取最新状态，当前不以 storage 事件替代事务。

## 必须继续处理的兼容点

1. draft 的 `InvestigationBlock` 无旧 `test_compare`，`review_direction` 也不等于旧 focus（index/source/uncertain/other）；`TestCase` 缺旧 intent/refs。导入完整保留在 `legacy.raw`，测试计划可转结构化查询；旧调查保存正文及原始结构，但其执行控件尚不能用这份 draft 无损接通。需要公共契约补齐或明确 legacy renderer 适配，不做错误枚举映射。
2. 导入的旧采用、时间和作者属于来源声明；服务端记录的是本次导入执行者和时间。新会话默认待检查，不把旧浏览器自报采用/测试当已验证事实。旧草稿保存在 provenance，现有编辑器挂载时需提供显式恢复草稿入口。
3. 共享入口尚未挂载。正式 W01 身份/事务/版本、W02 真实测试、W04 角色上下文、W05 交付/反馈消费，以及现有浏览器全流程均未联调。前端双语正常标签已有，controller 的部分错误解释仍需接到全局双语错误映射。
4. PostgreSQL未在本包实测；本包 SQLite 测试成功不构成 PG 支持声明。没有在线模型、MCP、真人或产品 QA 结果。
