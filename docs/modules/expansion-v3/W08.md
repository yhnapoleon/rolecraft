# 模型建议前端

原 v4 反馈区读取已有反馈的公开 `model_advice`，摘要默认折叠；摘要分行写状态标题、合成声明、逐句计数与（较浅的）作品级结论，展开后逐句显示原句、结果与可回跳引用，再写注册身份（类型、训练数据、权重阶段、融合分量与 alpha）。区块上方显示 provenance 记下的评价模型。该区域只读，不发起推理、评分或业务动作。各状态的具体文案、注册、worker、模型回传及真实条件见[模型运行说明](../../data/expansion-v3-w08.md#反馈页显示)。

- 文案在 `model-advice-copy.ts` 的中英成对表，原作品和历史反馈保持原文。等待模型、待核验、加载失败、超时、全部未判断、合成机制演示与外部候选建议依据结构化字段区分；建议明确不计分，不显示总分。
- 规则核实、模型建议与待核验按当前公开适用项分别计数，覆盖率行写「已核实 N 项／共 M 项适用 · 模型建议 K 项 · 待核验 P 项」（英文 `Verified N of M applicable items · Model advice K · Pending verification P`），不显示百分比；不适用及适用性未知项不进分母。已核实规则优先保留；关系建议 `INSUFFICIENT`、失败、synthetic 和权限不足进入待核验。同一验收项有多条关系建议时，全部可用且非 `INSUFFICIENT` 才计该项有建议。这是界面覆盖统计，不写回评分或后端报告。
- 分数区间行在适用项含适用性待确认项时写「规则已定标部分：a–b 分（适用项共 X 分，其中 Y 分适用性待确认，满分 100）」；没有待确认项时沿用「规则已定标部分：a–b 分（适用项共 X 分，满分 100）」或（适用项即满分时）「规则已定标部分：a–b 分（满分 100）」。
- 后端逐项权限投影是授权来源；前端只保留已验证的展示字段。权限刷新立即替换模型条目、引用和覆盖率，保留展开状态；焦点所在引用失效时移到摘要。未知或格式错误的单条建议局部降级，仍显示可读规则和其他建议。`task_type=criterion` 的建议条目读取时跳过，不把整块标成失败。
- 旧会话与无新字段的旧反馈沿既有入口读取；刷新、展开和历史读取不重新调用模型。受控样例只证明展示机制，真实模型质量、分语言效果与训练证据仍待负责方交付。

## 本地复验

在 `apps/web` 运行 `npx vitest run src/features/feedback-native`、`npm run build`。真实 DOM 专项使用同一 regression CDP driver：先将 `CHROME_BIN` 指向本机 Chromium，再运行 `npx vitest run --config src/features/feedback-native/model-advice.vitest.config.ts`；缺省占用 19810，可用 `MODEL_ADVICE_PORT` 换端口，退出自动停自己的服务。中英截图：`CHROME_BIN=… OUT=<新目录> node src/features/feedback-native/model-advice.shots.mjs`（缺省端口 19811，同样可用 `MODEL_ADVICE_PORT` 换）。带真实注册的正常入口中英走查用 `model-flows` 浏览器流程，见[模型运行说明](../../data/expansion-v3-w08.md#正常入口浏览器流程model-flows)。

| 失败模式 | 对应测试接缝 |
|---|---|
| MODEL-01/02：错误域、评分标记、synthetic 质量混入 | host 公开反馈适配器逐项拒绝；浏览器合成机制演示标识 |
| MODEL-03/05：刷新重复推理或改写旧结果 | host 只读恢复；旧反馈原文与原版本 |
| MODEL-04：越权引用或刷新残留 | host 安全字段解析；浏览器逐项替换、焦点和覆盖率 |
| MODEL-06：加载失败隐藏为成功 | 双语浏览器失败文案，作品保留且不发命令 |
| 界面状态、折叠、覆盖率和窄屏 | 双语真实 DOM Vitest；正常 v4 HTTP/worker 专项 |

本切片只完成前端承接及工程验证。完整组合门禁、真实模型及整张模型任务验收由总协调组织；没有因此关闭真实训练或语义质量条件。
