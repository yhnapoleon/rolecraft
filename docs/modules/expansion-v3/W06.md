2026-10-07：036接续034首版，固定 c9 `3b72c97` + W03 r6 `1271ae0` + W05 r6 `f43b17a`。当前为 implementation_only / partial。生产 app、总 CLI、原生界面、完整观察来源及公共并发限额尚未接入；本页不表示正式环境可连接。

## 已实现边界

- `api.delegations_v2.install_delegations(registry, source_provider=...)` 注册冻结的 delegation/observation/tools 槽位，返回绑定同一 Gateway 的函数。签发/撤销复用公共 V2Store；默认 read，最长有效期默认 3600 秒；只有 human 根身份签发。executor 由服务端形成，不读取客户端自报身份。act 不包含 submit。
- `delegations.observation.PublicSources` 是内部可信读取端口，由集成人用真实来源实现，不能传完整 ScenarioSpec。没有 provider 时 Observation 明确 503。材料目录、实际读取片段、显示记录及事件游标分开；对象/来源当前权限、会话和时点必须一致。材料是否公开、正文与收据是否真实、是否完整仍是 provider 的责任，hash 或类型校验不能证明这些事实。
- 工具由实际注册项及当前能力生成，冻结 `ToolSchema` 没有新增字段。method/path 为客户端内部映射，已与实际 app 路由逐一核对。未注册工具不出现；未齐的角色生成、反馈生成保持 unavailable。默认只启用已知同步写入；测试夹具显式开启的同步测试不代表生产后台 job 已可运行。
- MCP/HTTP 客户端只持委托身份，调用原公开 API，不保存另一份状态、凭据表、任务队列或权限系统。human 令牌不能用作 MCP 身份。配置、错误和业务结果经脱敏处理。
- 普通作品编辑拒绝 `removed=true` 或已移除的当前头；移除/恢复没有公开 MCP 工具。此限制不修复现有公共 HTTP 生命周期授权。待共同细粒度授权冻结后再启用，不能把通用 act 当作移除/恢复许可。
- `requests.read` 按原 request_id 恢复；JSON-RPC id 与业务 request_id 无关。`wait_request` 最多等待 30 秒，保留真实 job ID/status，needs_context 立即交回。零秒表示单次查询，网络请求仍受客户端超时限制。超时、取消或 EOF 都不证明业务未执行，继续查询原键，不能直接换键重做。

## 集成方法

由032在公共工厂/CLI串行接线；本包未编辑公共文件：

```python
from career_lab.api.delegations_v2 import install_delegations
bind_w06 = install_delegations(registry, source_provider=trusted_public_sources)
app = create_app(database_url, extensions=registry)
bind_w06(app.state.gateway)
```

`source_provider(view, page, auth)` 在公共授权 query 事务内调用，返回 `PublicSources`。必须从同一 VersionPoint 读取实际可见材料、实际获取收据/显示记录与事件，按真实 seq 扫描，私有事件消耗游标而不输出。不要从 catalog 推断已读。每条 read/ref 使用事务内 `reference_allowed`，不保留 callback 到事务之外；provider 不调用模型、不发网络请求、不另开授权事务。当前受控测试 provider 使用同一 SQLite 数据库的持久事件，但不是生产适配器或 PG 并发一致性证明。

`mcp.__main__.register_cli(commands)` 返回子命令 parser 并设置 `w06_handler`；总 CLI 在 parse 后调用 `args.w06_handler(args)`。独立模块入口已可使用；全局 `career-lab mcp` 尚未挂载。

## 本地运行

先由用户在已接入服务的授权入口创建短期委托。把 `api_url`、`session_id`、`token` 三个值写入当前用户所有的 0600 JSON 文件；API 地址仅允许 HTTPS 或 loopback HTTP。配置文件不得提交、发布或附入验收包，令牌不放命令行。可以通过环境变量 ROLECRAFT_MCP_CONFIG 提供**文件路径**。

```sh
env -u PYTHONPATH .venv/bin/python -m career_lab.mcp --config /absolute/private/delegate.json
env -u PYTHONPATH .venv/bin/python examples/byo_agent_minimal.py --config /absolute/private/delegate.json --journal /absolute/private/w06-journal.json --config-version 0
```

这些是用户自行配置后的使用命令。仓库不提供可复用令牌；当前生产 source provider 未装时 tools/list 会清楚失败，不能把这算作有效联调。

示例是明确执行 create/test 两个动作的无模型脚本，需人先调查并明确传入真实 config version；不自动采用或提交。私有 journal 在发送前保留原始业务命令，恢复时查询原键；旧 journal 保持同一计划。新任务使用新 journal。遇冲突或权限变化先检查真实结果，不改写 journal 假装成功。后续采用和提交由人分别执行并记录自己的 executor。示例不证明模型自主性、学习效果或工作效率。

客户端仅在 `requests.read` 的权威状态为 `completed` 后继续下一个动作。`pending`、`needs_context`、`failed` 和 `unresolved` 均保留原 request_id、job_id、origin response、各 job 的 effect/错误及刷新历史，不触发下一步。默认每个请求等待5秒，`--wait-seconds` 可设0—30，0表示单次查询；退出码0为两个动作完成，2为待处理，1为失败或结果尚未确认。待处理输出提供原请求和作业编号。需要刷新时由获准入口明确执行，客户端不会自动刷新、改键或重做。

新 journal 绑定API地址和服务端委托executor，凭据更换后不能接着重发旧计划。首版 journal 没有此绑定：已有“completed”也必须回查；404不自动重发旧命令，保留日志交原身份核对。已完成的旧请求可以正常恢复。任何响应丢失仍先查原键；接收确认和作业完成分别保存。

授权入口接受“Claude Code”或中文等正常显示名称，名称不参与权限、executor ID或路由；身份仍由服务端签发。名称支持中英不代表双语业务链已经验证。

## MCP 契约与来源

2026-10-07 已读取官方 [2026-07-28 基础协议](https://modelcontextprotocol.io/specification/2026-07-28/basic)、[版本](https://modelcontextprotocol.io/specification/2026-07-28/basic/versioning)、[stdio](https://modelcontextprotocol.io/specification/2026-07-28/basic/transports/stdio)、[tools](https://modelcontextprotocol.io/specification/2026-07-28/server/tools)、[discovery](https://modelcontextprotocol.io/specification/2026-07-28/server/discover) 与 [2025-11-25 lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle)。

实现现代逐请求版本/capabilities 元数据、discovery、tools/list、tools/call、ping，并提供显式 legacy initialize/initialized 兼容。没有 resources/prompts/sampling/tasks、服务器主动请求或远程 schema 解引用。schema 使用 2020-12。现代请求返回 resultType，发现/列表 cache TTL 为零；工具状态每次核验。这里只验证该 tools 子集，不声称完整 MCP 认证或所有客户端兼容。

UTF-8 每行一条 JSON；stdout 仅协议，固定诊断走 stderr。最大输入 1 MiB、最多16个在途协议请求、4个网络调用线程、每次 HTTP 上限30秒/响应8 MB。协议线程上限与**每委托后台 job 配额**是不同约束，前者不能替代后者。客户端取消只停止返回，不能撤回已经提交的业务效果。
