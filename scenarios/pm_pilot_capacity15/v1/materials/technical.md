# 技术约束 v1

- 默认容量：15名用户。主管明确批准扩容后可提高到60名。
- 当前开发资源：3人日。
- 当前索引：每日更新，源文档与索引可能相差24小时。源文档变化不会立即刷新索引。
- 实时同步：需要5人日，包含同步与适用域配置，不包含人工fallback。
- 范围过滤：1人日，支持排除动态政策或让政策问题直接转人工。
- 人工fallback：1人日，为范围外、缺少可靠依据和高风险问题提供人工入口。

工作项成本相加。实时同步加人工fallback共6人日，必须申请额外资源。主管批准资源变更后，总资源可变为6人日，上线期限可改为第10天。

测试记录必须保存源文档版本、索引版本和配置版本。回答听起来合理不能替代版本一致性核验。
