# 候选试点人群与需求差异

本案例的公司与业务资料为虚构训练设定。

候选新员工20人、运营员工20人、行政员工10人，共50人；他们不是同一类使用者。

新员工经常不知道入口在哪里，也不熟悉内部术语。稳定的操作指引可能有价值，但他们容易把助手给出的步骤误认为操作已经办理。账号、门禁、培训等事项仍需要本人或负责人完成。

运营员工出差频繁，关心的是当前适用标准及例外情况。他们对“请再找人核验”的耐心较低，也更容易根据一个确定金额作出承诺。错误政策回答的影响可能比一次FAQ回答失败更大。

行政员工熟悉流程，希望减少重复解释，同时担心低置信答案、转交不清和无人接管。自动回答率提高可能让统计好看，却未必减少总处理工作。

可以拆分人群，邀请人数不等于会同时使用的人数。已有样本没有按人群标注咨询量，不能直接推断每组上线后会贡献多少问题。若要选择优先对象，需要说明证据、假设与后续验证。
