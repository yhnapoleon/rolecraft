# 服务台导出 SD-120：工单登记与字段口径

本案例的公司与业务资料为虚构训练设定。

整理：吕雯｜一线值班组长。导出批次SD-120，筹备期最后10个工作日的已结单工单；“服务台”指现有的人工 IT 支持渠道，陈敏是本项目的业务负责人，不是这份导出的填报人。

样本窗口为10个工作日，筛选条件closed=true，共120张工单，涉及56名不同提单人。

分类常见 IT 问题：72次；接单到结单时长合计288分钟，均值4分钟；重复意图标记50次。

分类时限与流程：36次；接单到结单时长合计324分钟，均值9分钟；重复意图标记14次。

分类安全个案：12次；接单到结单时长合计168分钟，均值14分钟；重复意图标记2次。

导出合计：780分钟、66次重复标记；重复率字段以全部120次为分母，结果55%。

字段字典：duration_minutes = closed_at − accepted_at。等待用户补截图、排队转派二线和复核期间，系统不暂停计时。repeat_intent由当班人员按相近问法手动勾选。导出没有“工程师实际处理分钟”字段。

原始行摘录：SD-014，VPN 无法连接，接单09:10/结单09:14，备注“发指引，等用户确认”；SD-061，P2 时限例外，接单10:20/结单10:38，备注“10:23转给业务负责人”；SD-089，账号核验，接单14:05/结单14:17，备注“用户补信息”。这些行已计入上面的分类合计。

吕雯附注：未结单工单没有进入SD-120；未逐条填写满意度、一次解决率或工程师操作时长。若需核对，可带导出批次、行号和字段名与陈敏讨论现有记录；仍缺的原始资料由陈敏协调，收到后另附来源。
